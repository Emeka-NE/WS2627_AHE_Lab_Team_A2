# Modern Hardware Description Languages

**Seminar Topic:** Modern Hardware Description Languages  
**Team:** A2

## Overview

This folder contains the seminar work on **Modern Hardware Description Languages**.

The seminar focuses on four modern hardware description languages: **Chisel, SpinalHDL, Clash, and Amaranth**. The aim is to investigate how these languages can improve hardware design productivity, reusability, and verification compared to traditional VHDL.

The research also covers key concepts such as embedded DSLs, parameterization, and type systems, as well as the challenges of adopting modern HDLs in industry.
